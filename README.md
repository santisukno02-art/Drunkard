# 🍻 Party Games

เว็บเกมปาร์ตี้แบบ Static Web App สำหรับเปิดบนมือถือและเล่นด้วยกันในวง

## เกม

1. 🎲 ลูกเต๋า — ลูกเต๋า 3D แบบ CSS มี animation ตอนทอย และเพิ่มจำนวนลูกได้
2. 🃏 เกมไพ่ — จั่วไพ่ป๊อกทีละใบ และเก็บไพ่ที่จั่วแล้วไว้ดูย้อนหลังจนกดรีเซ็ต
3. 🔥 จิ้มนิ้ว — แตะหลายคน ค้าง 3 วินาที วงนิ้วใหญ่ขึ้น สีต่างกัน และสุ่มเลือก 1 นิ้ว
4. 🃏 ไพ่โดเรม่อน — สำรับ 52 ใบ A-K x 4 ดอก พร้อมความสามารถประจำอันดับไพ่
5. 👑 King Game — กำหนด 2–10 คน แจกไพ่ให้ครบตามจำนวน แต่ละคนเปิดไพ่ของตัวเอง และ K คือ KING
6. 🔥 ไพ่คำสั่ง — สุ่มคำสั่ง
7. 🏃 สัตว์วิ่งแข่ง — เลือกสัตว์ 2–10 ตัว ระบบสุ่มระยะ 5/10/15M และ Map ทุกครั้ง

## กติกาไพ่โดเรม่อนที่ใส่ใน Prototype

ใช้ 52 ใบ = A, 2–10, J, Q, K จำนวน 4 ดอก โดยความสามารถผูกกับอันดับไพ่:

A = กินคนเดียว
2 = หาเพื่อน 1 คน
3 = หาเพื่อน 2 คน
4 = เพื่อนฝั่งซ้าย
5 = ทุกคน
6 = เพื่อนฝั่งขวา
7 = ดวลปอด
8 = Relax
9 = มินิเกม
10 = ทาแป้ง/ภารกิจ
J = จับหน้า
Q = แหม่มเพื่อนไม่คบ
K = KING

รายละเอียดบางกติกาอาจต่างกันตามวง/ชุดการ์ด ดังนั้นสามารถแก้ข้อความใน `doraAbilities` ใน `app.js` ได้

## Deploy
